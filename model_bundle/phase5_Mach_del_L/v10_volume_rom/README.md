# 전체 체적 마하수 POD–GPR

기존 2D 모델과 동결 예측을 보존하고, 27개 정상 CFD 조건의 전체 1/4 체적 마하수장을 별도 모델로 학습한다. M1.75와 M3.25 CFD는 이 새 모델의 사후 독립 조건 평가에만 사용한다. 브라우저 표시용 표본 수와 학습에 사용하는 원래 체적 셀 수는 구분한다.

격자 대응 검증과 추출이 끝난 뒤 다음 명령으로 실행한다.

```bash
OPENBLAS_NUM_THREADS=4 python3 train_volume.py
python3 -m unittest test_volume_rom.py
```

`results/cache/extraction_manifest.json`에서 모든 조건의 셀 대응이 확인되어야 학습을 시작한다. 동일한 노드·면·셀 개수만으로 셀 순서가 일치한다고 가정하지 않는다. 실제 원본의 셀 번호 순서는 조건마다 다르므로, 경계에서 시작한 격자 연결성을 이용해 공통 논리 격자의 셀 순서로 재배열한 `registered_mach.npy`만 사용한다.

전체 셀을 열로, CFD 조건을 행으로 하는 스냅샷 행렬을 사용한다. 기준 형상인 M17의 실제 셀 체적을 고정 가중치로 사용하고, 작은 Gram 행렬을 블록별로 누적한 뒤 조건 축에서 평균 제거와 고유치 분해를 수행한다. 여러 원본 ASCII 파일은 제한된 좌표 정밀도로 벽 근처 일부 셀 체적이 퇴화하지만, 정밀도가 더 높은 M17은 모든 셀의 양의 체적과 닫힌 형상 검증을 통과한다. 따라서 임의의 체적 하한이나 셀 제외 없이 모든 3,533,741개 셀의 마하수를 학습한다. 가중치는 **고정된 M17 기준 형상에서의 물리 체적 적분**이며 각 변형 조건 자체의 체적 적분과 구분한다. 350만 셀 제곱 크기의 공간 공분산을 생성하지 않는다. POD 누적 에너지 목표는 0.9999, 최대 계수 수는 26이며 이 정책은 평가 전에 고정한다. 각 계수에는 기존 모델과 같은 Matérn 5/2 GPR을 적용한다. 입력은 L과 전압력이며, GPR 내부에서는 L과 ln(P0)를 훈련 조건만으로 정규화한다.

조건 하나 전체를 제외하는 LOCO 검증의 각 fold에서 평균장, POD 기저·차수, 입력 정규화, 계수 정규화와 GPR 하이퍼파라미터를 다시 계산한다. 서로 다른 셀을 임의로 나누는 검증은 하지 않는다. Gram 이차형식으로 완전한 체적장의 오차를 계산하므로 검증도 표시용 부분 표본으로 제한되지 않는다. POD 투영 오차와 실제 GPR 예측 오차를 각각 기록한다.

평가 영역은 전체 체적, 기준 x ≤ 0 m, 기준 x > 0 m, 기준 −0.5 ≤ x ≤ 0.5 m이다. 하류 오차와 상류 오차를 구분할 수 있도록 영역별 기준 체적 가중 결과를 함께 기록한다. 영역 좌표는 M17 기준 형상의 대응 셀 중심이다. 두 독립 CFD 조건은 보조 지표로 동일 셀 가중 오차와 전체 셀의 최대 절대 오차, 음의 예측 개수 및 예측 범위도 기록한다. 예측값을 임의로 잘라 오차를 낮추지 않는다. 이 평가는 정합된 셀의 장 예측 오차이며 별도의 형상 보간 오차를 포함하지 않는다.

`results/model/mean.npy`와 `modes.npy`에는 모든 대응 체적 셀의 평균장과 POD 기저가 float32로 저장된다. 작은 `coefficient_model.pkl`에는 GPR과 스냅샷 조합 계수가 들어 있다. `volume_rom.load_native_model()`과 `predict_native()`로 전체 체적장을 복원할 수 있다. 원래 셀 해상도에서 추론한 결과와 float64 Gram 오차가 일치하는지 별도로 확인한다.

현재 원래 셀 해상도 모델의 저장량은 약 286 MiB이며 로컬 연구 결과로 보관한다. GitHub Pages에는 이 전체 모델에서 추출한 표시용 평균장·기저, 형상과 운전 경로 계수만 배포한다. 표시 자산을 줄여도 학습과 위 검증은 전체 체적 셀을 대상으로 수행한다. `--reuse-grams`는 정합된 마하수 배열, 기준 체적, 기준 셀 중심, 조건 메타데이터와 Gram 생성 코드의 SHA-256이 모두 일치할 때만 허용한다.

정상 CFD 스냅샷의 준정상 장 모델이다. 시뮬레이터 시간축을 따라 표시해도 비정상 유동 학습, 실험 동기화 또는 독립적으로 검증된 제어기가 되지 않는다. 1/4 체적의 마하수는 대칭면에 대해 값의 부호를 바꾸지 않고 시각화 단계에서만 반사한다.
