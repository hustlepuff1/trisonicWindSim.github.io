단면 ROM 중앙 평균가정된 센서Mach 제어 목표
모델 가정과 표시 범위
  • 유동장은 현재 L과 자동 연동된 P₀에 대한 정상 CFD 기반 ROM의 예측입니다. 구동기·센서 동특성은 가정값이며, 압력은 현재 위치의 설계 스케줄을 지연 없이 따릅니다. 실제 비정상 CFD·압력 조절기·풍동 실험 결과가 아닙니다.
  • Mach 모드의 피드백은 시험부 단면 ROM에서 중앙 100×100 mm 영역을 적분한 평균값을 바탕으로 합니다. 이전 스칼라 대리모델의 저장된 궤적을 재생하지 않습니다.
  • 목높이는 상·하 벽 사이의 전체 높이입니다. 노즐 그림은 상반면이며, 단면 그림은 ¼ 해석 영역을 CFD 대칭 가정에 따라 반사해 표시합니다.
  • 80 kg/s는 설계 질량유량 목표입니다. 기존 new CFD의 실제 질량유량은 약 72–75 kg/s이며, 이 시뮬레이터가 80 kg/s 유지를 검증하거나 보장하지 않습니다.
  • 상단 배지는 현재 입력의 학습범위 포함 여부입니다. 학습범위 내부도 독립 검증 완료를 뜻하지 않으며, 새 운전점은 별도 CFD 검증이 필요합니다. M1.75 사전 고정 예측
  • 3D는 입구부터 시험부 x = 0까지의 노즐 체적 마하수로 별도 학습한 모델입니다. 같은 현재 L과 설계 경로의 P₀를 사용하며, 표시는 ¼ 영역의 대칭 복원과 화면용 격자 재구성입니다. 제어 피드백은 기존 시험부 단면 모델을 계속 사용합니다. 3D 색은 절대 Mach이고, ΔMach·높이 확대 선택은 2D에 적용됩니다.
  • ΔMach는 초기화 당시와 같은 정규화 좌표의 차이이며, 움직이는 벽 아래 고정 물리 위치의 차이와 다릅니다. 색과 형상 확대는 표시 기능이며 계산값을 바꾸지 않습니다.
