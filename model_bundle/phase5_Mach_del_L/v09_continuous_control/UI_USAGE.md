# 연속 운전 시뮬레이터 사용법

[시뮬레이터 HTML](../../../index.html)을 Firefox에서 열면 됩니다. 인터넷 연결이나 별도 웹서버는 필요하지 않습니다. v08의 독립 운전점 선택을 없애고, 하나의 L–P₀ 설계 운전 경로를 따라 명령을 연속 변경하도록 구성했습니다.

## 직접 조작

1. 초기 상태는 중앙 평균 Mach 1.5입니다. `1.75` 버튼을 누르거나 숫자 입력창에 원하는 Mach를 입력합니다.
2. 명령 변경 시 현재 L·속도·시간이 유지됩니다. PI 제어와 가정된 구동기 응답에 따라 L이 움직이고, 종단면과 시험부 단면이 함께 갱신됩니다.
3. **명령 P₀**는 목표 위치에 대응하는 총압입니다. **현재 P₀**는 현재 실제 L에 대응하는 스케줄 값을 즉시 따릅니다. 별도 압력 조절기의 지연이나 압력 제어 루프는 포함하지 않았습니다.
4. `전체 목높이` 모드에서는 상·하 벽 사이의 전체 높이(mm)를 명령합니다. 모드를 바꿔도 위치·시간은 유지되며, 현재 제어량에서 새 목표를 시작합니다. Mach 바로가기 버튼은 초기화 없이 Mach 모드로 바꾼 뒤 해당 목표를 설정합니다.
5. `일시정지` 중에는 명령을 바꿔도 위치가 움직이지 않습니다. `재개` 후 응답이 이어집니다. `초기화`만 시간과 이력을 처음으로 되돌립니다. 이력을 보관하려면 초기화 전에 CSV를 저장합니다.

표시 속도 0.5×–8×는 브라우저에서 시뮬레이션 시간이 진행하는 배율입니다. 계산 시간 간격과 구동기 모델의 속도 제한은 바뀌지 않습니다. `현재값을 목표로`는 현재 제어량을 목표로 설정하는 기능이며, 구동기를 즉시 정지시키는 명령이 아닙니다.

## 유동장과 피드백

- 노즐 종단면은 y=0 상반면입니다. 높이 1×는 실제 길이 비율이고, 2×·4×는 표시만 확대합니다. 축 눈금과 계산 형상은 실제 단위를 유지합니다.
- 시험부 단면은 x=0의 ¼ CFD 영역을 대칭 가정으로 반사한 전체 단면입니다. 중앙 점선 사각형은 100×100 mm Mach 피드백 영역입니다.
- Mach 제어의 센서 입력은 현재 단면 ROM에서 이 영역을 적분한 면적 평균값에 가정된 센서 필터를 적용한 값입니다. 이전 스칼라 모델의 시간 이력을 재생하지 않습니다.
- `ΔMach`는 초기화 시점의 ROM에 대한 차이입니다. 비교 좌표는 벽에 맞춘 정규화 좌표이므로, 같은 고정 물리 위치에서 두 유동장을 뺀 결과와 다릅니다. 색범위는 전체 운전 경로에서 고정됩니다.
- 검은 외곽선은 현재 형상, 주황 점선은 명령 위치의 형상입니다. 두 선이 겹쳐 보일 때는 아래 위치 오차와 시간 이력을 함께 확인합니다.

## 발표와 저장

`발표 화면`은 부가 설명을 접고 그림을 넓힙니다. `전체화면`은 브라우저 전체화면을 사용합니다. `현재 화면 PNG`는 현재 명령·총압·두 유동장·응답 그래프·모델 가정을 한 장으로 저장합니다. `이력 CSV`에는 모든 계산 시점과 명령·모드 변경 이벤트, L·전체 목높이·Mach·현재/명령 P₀·학습범위 상태가 포함됩니다. 그래프는 최근 120 s만 표시할 수 있지만 CSV에는 초기화 이후 전체 이력이 남습니다.

## 해석 범위

**80 kg/s는 설계 질량유량 목표입니다.** 기존 new CFD의 실제 질량유량은 약 72–75 kg/s이며, 이 시뮬레이터가 80 kg/s 유지를 검증하거나 보장하지 않습니다. 유동장은 정상 CFD 기반 ROM의 준정상 재구성입니다. 시간응답은 가정된 구동기·센서 동특성과 이상적인 압력 스케줄 추종에서 나온 결과이며, 실제 비정상 CFD 또는 풍동 시험 결과가 아닙니다.

연속 경로의 801개 노드와 800개 중간점은 기존 학습 입력의 convex hull 내부로 확인되었습니다. 상단 배지는 현재 입력의 포함 여부를 매번 계산해 표시하며, 배지의 도움말에는 명령 위치의 상태도 표시합니다. `학습범위 내부` 역시 독립 검증 완료를 뜻하지 않습니다. 새 운전점은 별도 CFD로 확인해야 합니다.

[M1.75 사전 고정 예측](../../../frozen_validation/M1p75/prediction.json)은 새 CFD 결과를 보기 전에 저장한 비교 기준입니다. CFD와 비교할 때에는 총압·L·형상과 중앙 100×100 mm 영역의 평균 정의를 맞춰야 합니다.
