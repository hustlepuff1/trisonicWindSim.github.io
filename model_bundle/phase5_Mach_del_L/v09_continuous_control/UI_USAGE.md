# 연속 운전 시뮬레이터 사용법

[공개 시뮬레이터](https://hustlepuff1.github.io/trisonicWindSim.github.io/)를 열면 기존 2D 화면으로 시작합니다. `2D 단면`, `노즐 3D`, `함께 보기`에서 표시를 선택합니다. 하나의 L–P₀ 설계 운전 경로를 따라 명령을 연속 변경하며, 보기를 바꿔도 현재 위치와 시간은 유지됩니다.

2D 모델과 화면 코드는 [HTML](../../../index.html)에 포함됩니다. 시험부 상세 결과와 3D에 사용하는 마하수·형상 데이터는 페이지를 열 때 같은 사이트의 `volume/`에서 자동으로 불러옵니다. 외부 CDN이나 별도 계산 서버는 사용하지 않습니다. 파일을 직접 여는 `file://` 방식에서는 2D만 사용할 수 있습니다. 내려받은 저장소에서 상세 결과와 3D를 보려면 저장소 최상위에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/`을 여세요. 유동장 그림 아래의 `시험부 상세 결과`는 2D / 3D / 함께 보기 모두에서 표시되며 현재 운전점과 함께 갱신됩니다. Mach–z와 Mach–y는 가로축 Mach 1–4 고정, 세로축 z·y(m)이고, Mach–x는 입구부터 x=0까지의 노즐 중심선입니다. `분포 CSV`와 `분포 PNG`로 저장할 수 있습니다. 로딩 중 표시되는 용량은 데이터의 다운로드 진행률입니다. 연결이 끊기면 `다시 불러오기`를 누릅니다.

## 직접 조작

1. 초기 상태는 중앙 평균 Mach 1.5입니다. `1.75` 버튼을 누르거나 숫자 입력창에 원하는 Mach를 입력합니다.
2. 명령 변경 시 현재 L·속도·시간이 유지됩니다. PI 제어와 가정된 구동기 응답에 따라 L이 움직이고, 종단면과 시험부 단면이 함께 갱신됩니다.
3. **명령 P₀**는 목표 위치에 대응하는 총압입니다. **현재 P₀**는 현재 실제 L에 대응하는 스케줄 값을 즉시 따릅니다. 별도 압력 조절기의 지연이나 압력 제어 루프는 포함하지 않았습니다.
4. `전체 목높이` 모드에서는 상·하 벽 사이의 전체 높이(mm)를 명령합니다. 모드를 바꿔도 위치·시간은 유지되며, 현재 제어량에서 새 목표를 시작합니다. Mach 바로가기 버튼은 초기화 없이 Mach 모드로 바꾼 뒤 해당 목표를 설정합니다.
5. `일시정지` 중에는 명령을 바꿔도 위치가 움직이지 않습니다. `재개` 후 응답이 이어집니다. `초기화`만 시간과 이력을 처음으로 되돌립니다. 이력을 보관하려면 초기화 전에 CSV를 저장합니다.

표시 속도 0.5×–8×는 브라우저에서 시뮬레이션 시간이 진행하는 배율입니다. 계산 시간 간격과 구동기 모델의 속도 제한은 바뀌지 않습니다. `현재값을 목표로`는 현재 제어량을 목표로 설정하는 기능이며, 구동기를 즉시 정지시키는 명령이 아닙니다.

## 유동장과 피드백

- 노즐 종단면은 y=0 상반면입니다. 높이 1×는 실제 길이 비율이고, 2×·4×는 표시만 확대합니다. 축 눈금과 계산 형상은 실제 단위를 유지합니다.
- 시험부 단면은 x=0의 ¼ CFD 영역을 대칭 가정으로 반사한 전체 단면입니다. 중앙 점선 사각형은 100×100 mm Mach 피드백 영역입니다.
- Mach 제어의 센서 입력은 현재 단면 ROM에서 이 영역을 적분한 면적 평균값에 가정된 센서 필터를 적용한 값입니다. 이전 스칼라 모델의 시간 이력을 재생하지 않습니다.
- `ΔMach`는 초기화 시점의 ROM에 대한 차이입니다. 비교 좌표는 벽에 맞춘 정규화 좌표이므로, 같은 고정 물리 위치에서 두 유동장을 뺀 결과와 다릅니다. 색범위는 전체 운전 경로에서 고정됩니다.
- 검은 외곽선은 현재 형상, 주황 점선은 명령 위치의 형상입니다. 두 선이 겹쳐 보일 때는 아래 위치 오차와 시간 이력을 함께 확인합니다.

## 노즐 3D 마하수

3D는 27개 CFD 조건에서 **입구부터 시험부 x = 0까지의 ¼ 노즐 체적 마하수**를 학습한 별도 POD–GPR 모델입니다. 학습 범위와 화면의 끝점 모두 시험부 x = 0입니다. 3D 그림은 화면용 격자에서 재구성하며, 학습 셀 수와 표시 격자 크기는 그림 아래에서 확인합니다.

- `내부 단면 + 형상`은 이동하는 격자 횡단면, 선택한 중심 대칭면, 형상 외곽선을 함께 표시합니다. `전체 표면`에서는 외부 표면의 마하수를 확인합니다. 전체 표면을 선택하면 내부 단면 조작은 비활성화됩니다.
- `격자 횡단면` 슬라이더로 입구부터 시험부까지 위치를 옮깁니다. 내부 격자 층은 정확히 일정한 x를 갖는 평면과 다를 수 있어 `x ≈ … m`로 표시합니다. 위치 값에 마우스를 올리면 해당 층의 실제 x 범위를 확인합니다. 마지막 단면은 정확한 **x = 0 평면**이며, `시험부 · x = 0` 버튼으로 바로 이동합니다. 처음 3D를 열 때도 이 시험부 단면을 표시합니다.
- `대칭 복원 · 전체`는 CFD의 대칭 조건에 따라 y = 0, z = 0에서 ¼ 형상을 반사합니다. 마하수는 스칼라이므로 반사할 때 부호를 바꾸지 않습니다. `CFD 해석 영역 · ¼`을 선택하면 실제로 해석한 사분 영역만 표시합니다.
- 마우스 드래그 또는 한 손가락으로 회전합니다. 휠 또는 두 손가락으로 확대·축소하고, `Shift + 드래그` 또는 마우스 오른쪽 드래그로 그림을 이동합니다. `시점 초기화`로 기본 시점에 돌아옵니다.
- 키보드로는 그림을 선택한 뒤 방향키로 회전하고 `+`·`−`로 확대·축소합니다. `Home`은 시점을 초기화합니다. 3D는 모든 축에서 실제 길이 비율을 사용합니다.
- 3D 색은 고정 색범위의 **절대 마하수**입니다. 3D 색범위는 노즐 모델의 예측 범위를 기준으로 정하며 2D와 다를 수 있습니다. 두 모델을 비교할 때 각 그림의 범례 숫자를 확인합니다. 2D의 `ΔMach`와 높이 확대 선택은 2D 그림에 적용됩니다. `함께 보기`에서는 두 모델을 같은 현재 L과 연동 총압에서 비교합니다.

노즐 체적 모델의 독립 CFD 비교 결과와 오차, 예측값의 범위는 [3D 검증 결과](../../../volume/validation.html)에서 확인합니다. 고정 색범위 바깥의 값은 색상표의 끝색으로 표시하며, 모델 예측값 자체를 절삭하지 않습니다.

3D 보기는 기존 제어기를 변경하지 않습니다. Mach 피드백과 센서 응답은 기존 시험부 2D 단면 모델을 계속 사용합니다. 3D 모델의 계수와 형상은 화면에 표시되는 현재 L에 따라 갱신됩니다. 마하수 명령을 바꾼 순간 목표 유동장으로 건너뛰지 않습니다.

## 발표와 저장

`발표 화면`은 부가 설명을 접고 그림을 넓힙니다. `전체화면`은 브라우저 전체화면을 사용합니다. `2D 단면`에서 `현재 화면 PNG`는 현재 명령·총압·두 유동장·응답 그래프·모델 가정을 한 장으로 저장합니다. `노즐 3D` 또는 `함께 보기`에서는 버튼이 `3D 그림 PNG`로 바뀌며, 현재 회전·확대·단면·대칭 설정의 3D 그림과 운전점·색범위를 저장합니다. 3D 로딩이 끝나야 저장할 수 있습니다. `이력 CSV`에는 모든 계산 시점과 명령·모드 변경 이벤트, L·전체 목높이·Mach·현재/명령 P₀·학습범위 상태가 포함됩니다. 그래프는 최근 120 s만 표시할 수 있지만 CSV에는 초기화 이후 전체 이력이 남습니다.

## 해석 범위

**80 kg/s는 설계 질량유량 목표입니다.** 기존 new CFD의 실제 질량유량은 약 72–75 kg/s이며, 이 시뮬레이터가 80 kg/s 유지를 검증하거나 보장하지 않습니다. 유동장은 정상 CFD 기반 ROM의 준정상 재구성입니다. 시간응답은 가정된 구동기·센서 동특성과 이상적인 압력 스케줄 추종에서 나온 결과이며, 실제 비정상 CFD 또는 풍동 시험 결과가 아닙니다.

연속 경로의 801개 노드와 800개 중간점은 기존 학습 입력의 convex hull 내부로 확인되었습니다. 상단 배지는 현재 입력의 포함 여부를 매번 계산해 표시하며, 배지의 도움말에는 명령 위치의 상태도 표시합니다. `학습범위 내부` 역시 독립 검증 완료를 뜻하지 않습니다. 새 운전점은 별도 CFD로 확인해야 합니다.

[M1.75 사전 고정 예측](../../../frozen_validation/M1p75/prediction.json)은 기존 2D 모델에서 새 CFD 결과를 보기 전에 저장한 비교 기준입니다. 이 기록은 3D 모델의 사전 고정 예측이 아닙니다. CFD와 비교할 때에는 총압·L·형상과 중앙 100×100 mm 영역의 평균 정의를 맞춰야 합니다.
