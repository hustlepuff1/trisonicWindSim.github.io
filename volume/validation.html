노즐 3D 마하수 모델 검증

사용자가 지정한 노즐 범위에 대해 27개 CFD 조건의 평균장·POD 기저·차수·모든 GPR을 새로 학습했다. 기존 2D 모델과 제어 계산은 유지한다.

학습과 표시의 끝점: 시험부 x = 0

평가 대상은 입구부터 x = 0까지의 ¼ 노즐 체적이다. 학습 조건을 대칭 복사하지 않고, 표시할 때 y = 0과 z = 0에서 형상을 반사한다.

입구시험부 · x = 0

입구측 286개 층의 원래 셀 1,441,726개는 값을 유지했다. 끝단에서는 x = 0까지 남는 셀 부분을 횡방향 열별로 합쳐 마지막 층 5,041개를 구성했다. 이때 셀 체적과 마하수의 체적적분을 보존하는 체적 가중 평균을 사용했다. 마지막 표시 단면의 모든 절점은 정확히 x = 0이다.

학습에서 제외한 CFD 조건

조건 단위 교차검증

27회 LOCO에서 매번 CFD 조건 하나 전체를 제외하고 평균장·POD 기저·차수·입력 정규화·GPR을 다시 학습했다. 노즐 체적의 조건 간 제곱평균 RMSE는 0.00737 Mach, 조건별 상대 L₂ 오차 평균은 0.49%였다.

제외한 조건 중 23개는 해당 fold의 학습 입력 볼록껍질 밖에 있었다. 최종 모델과 모든 교차검증 fold에서 선택된 GP 최적화가 수렴했다. 공간 셀을 무작위로 나누는 검증은 사용하지 않았다.

형상 보간의 별도 검사

예측값의 수치 범위

GPR은 마하수의 비음수 조건을 강제하지 않는다. 다음 값은 각 독립 조건의 모든 공통 노즐 셀에서 확인했으며, 오차 계산과 저장에서 음수를 절삭하지 않았다.

웹 표시와 조회 오차

학습에 사용한 1,446,767개 공통 노즐 셀로 만든 모델을 웹에서는 97,083개 표시 절점으로 재구성한다. 표시 절점의 마하수는 인접 셀 평균이다. 내부 횡단면은 격자 좌표면이므로 x≈ 값과 실제 x 범위를 함께 표시하고, 마지막 시험부 단면은 정확한 x = 0 평면으로 표시한다.

브라우저 경로 조회값을 구간 중점 1,600개에서 직접 GP 계산과 비교했다. 최대 기준 체적 RMSE는 3.00e-06 Mach, 최대 표시 절점 차이는 1.31e-05 Mach였다. 이는 모델 자체의 CFD 예측 오차와 별개의 구현 검사다.

해석 범위와 재현 자료
